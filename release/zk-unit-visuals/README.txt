R.E.D ZKidz: Mass Armies Unit Visual
====================================

Smaller units in larger numbers. Civilization VII only loads unit art from its own
Overrides folder, never from a mod folder, so this mod comes as an installer.

Install
  1. Unzip this folder somewhere it can stay (for example Documents\ZKidz Unit Visuals).
  2. Close Civilization VII.
  3. Double-click install.bat.
  4. Start the game.

Windows may warn that the program is unrecognised: click "More info", then "Run anyway".

After a game patch the visuals rebuild themselves the next time you log in to Windows,
as long as this folder is still there.

Uninstall
  Double-click uninstall.bat before you delete this folder. It removes only the files
  the installer wrote, plus its login entry.

The installer reads your game's own art files and writes patched copies to
%LOCALAPPDATA%\Firaxis Games\Sid Meier's Civilization VII\Overrides\Local.
Your game installation itself is never changed.
